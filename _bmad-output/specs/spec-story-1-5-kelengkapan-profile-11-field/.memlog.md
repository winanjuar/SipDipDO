- (capability) CAP-2 Indikator langkah: menunjuk PERSIS field yang belum lengkap (nama field, bukan sekadar hitungan); seluruh 10 terisi -> Profil dinyatakan lengkap - prasyarat verifikasi COO terpenuhi (FR-22 gerbang: registrasi -> Profile lengkap -> verifikasi).
- (capability) CAP-3 Gerbang navigasi: calon owner belum lengkap hanya melihat Kelengkapan Profile + status (tanpa nav lain); akses URL langsung ke permukaan lain ditolak di batas server -> redirect (AD-8, UX-DR14).
- (capability) CAP-4 Cron pengingat & kedaluwarsa: job harian CRON_SECRET, batas hari dihitung zona Asia/Jakarta di dalam endpoint (AD-9); H-3 -> email pengingat enqueue ke outbox untuk pendaftar diajukan belum lengkap; hari ke-7 -> diajukan->kedaluwarsa via CAS + audit; sebelum H-3 atau sudah lengkap -> tanpa aksi.
- (capability) CAP-5 Re-daftar kedaluwarsa: pendaftar kedaluwarsa mendaftar ulang email sama -> CAS kedaluwarsa->diajukan pada baris owner YANG SAMA (id tetap), tercatat audit, tanpa baris baru (unique email AD-11).
- (capability) CAP-6 Submit gagal non-validasi: isian form dipertahankan + toast 'Tidak dapat menyimpan - coba lagi.' verbatim (UX-DR19); tanpa pengisian ulang dari nol.
- (constraint) AD-11 satu penulis: hanya IDENTITAS menulis status owner; setiap transisi = CAS atas status sebelumnya dalam satu transaksi DB; race tiga penulis (simpan kelengkapan vs cron kedaluwarsa vs verifikasi COO Story 1.6) dijaga CAS yang sama dengan AD-2; enum dipinku diajukan|terverifikasi|ditolak|kedaluwarsa|keluar.
- (constraint) AD-3 + AD-5 audit: entry append-only {actor, action, target, details} ditulis in-tx dengan aksinya; action dari registry enum terpusat; modul identity menulis audit hanya via API publik modul audit (index.ts), tidak pernah menulis tabel tetangga.
- (constraint) AD-9 kalender: batas hari (H-3, hari ke-7) dihitung di dalam endpoint/service zona Asia/Jakarta via helper shared/domain (jakartaDayKey, addCalendarDays) - bukan jam trigger UTC cron; parameter today injectable pada service untuk uji boundary fixed-clock.
- (constraint) AR-6 outbox: email pengingat ditulis sebagai baris outbox in-tx (modul proofs), kirim async + retry terpisah - tidak pernah kirim sinkron di jalur transaksi; kegagalan kirim tidak menggagalkan job.
- (constraint) AD-8 batas server: evaluasi akses halaman/API kelengkapan profile dilakukan middleware/handler server, tidak pernah di klien saja; cron endpoint terproteksi CRON_SECRET (timing-safe) - endpoint /api/jobs/daily sudah ada dan job pendaftar mendelegasikan ke service identity.
