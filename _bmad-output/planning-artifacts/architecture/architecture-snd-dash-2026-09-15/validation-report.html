highF4 — Bukti Transaksi tanpa titik potong waktu → unduh ulang menunjukkan angka beda dari email asliadversarial · P4 · State

highF5 — Tangga lock tak mencakup keluarga tx rekap DISTRIBUSI → deadlock / rekap imutabel Σ≠100%adversarial · P5 · AD-2/AD-11

highF6 — Format kawat uang string vs number tak dipinkan → pratinjau ≠ validasi server di input batasadversarial · P6 · AD-10

Fix: uang & ratio sebagai string desimal berskala tetap lintas batas API/SSR; SATU pasangan parse/serialize di shared/domain; larang Number()/parseFloat() atas uang/ratio + baris Don't.
highF7 — Derivasi role/keterbukaan/referral & enum status owner tak dipinkanadversarial · P8 · AD-8/AD-11
Akses via shares live vs via status tersimpan → kompensasi AD-1 yang meng-nol-kan shares salah mengunci owner berhak; himpunan referral beda antara submit dan konfirmasi.
Fix: enum siklus hidup owner dipinkan + first_effective_at oleh event Pembelian Pertama; aksesPenuh/perluReferral/pilihanReferral = fungsi kanonik tunggal IDENTITAS, bukan dari shares live.
highF8 — Poin lintas ≥2 cut-off: "ditandai selesai" vs "ditunaikan" ambigu → Insentif salah dibekukanadversarial · P14 · AD-6/AD-10

Fix: definisi tegas dua istilah; rekap = Σ semua periode ter-finalisasi-belum-tertunaikan; penandaan tertunaikan atomik dengan simpan rekap.
